# ClinicOS

ClinicOS is a modern clinic appointment scheduling and management platform.


## Overview

The application helps multi-provider clinics manage:

- providers
- patients
- availability
- appointments
- visit notes
- appointment history
- analytics


## Technology Stack

Frontend:

- Next.js 15
- TypeScript
- Tailwind CSS
- shadcn/ui


Backend:

- Next.js Server Actions
- API Routes


Database:

- PostgreSQL
- Prisma ORM
- Supabase


Authentication:

- Auth.js
- JWT


## Local Development

Environment variables are required.

Create:

.env.local

and add:

DATABASE_URL

DIRECT_URL

AUTH_SECRET

AUTH_URL
